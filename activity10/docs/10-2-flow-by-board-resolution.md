# กิจกรรมที่ 10.2 — แผนผังไฟล์แยกตามมติบอร์ด (1 มติบอร์ด ต่อ 1 flow)

จุดร่วมของทั้ง 3 flow คือ [10-2-10-legal-admin-receive-outcome.html](../10-2-10-legal-admin-receive-outcome.html) (ธุรการรับมติบอร์ด) — ก่อนหน้านั้นทุกคำร้องเดินไฟล์ชุดเดียวกัน (Part 1) หลังจากนั้นไฟล์จะแยกกันตามผลมติบอร์ด (`l2ResolutionType` / สถานะคดี) ตามตารางด้านล่าง

คอลัมน์ **"สถานะที่แสดงใน 01-work-inbox.html"** ด้านล่างคือค่า `status` (และ `statusCode`) ที่ธุรการ/นิติกร/ผู้บริหารเห็นในคอลัมน์ "สถานะ" ของหน้ารายการงาน **ระหว่างที่คำร้องกำลังรอให้ผู้มีสิทธิ์กดปุ่ม "ดำเนินการ" เข้าไปที่ไฟล์ในแถวนั้น** (ค่านี้ถูกเขียนไว้บนคำร้องโดยหน้าก่อนหน้าในลำดับ ดู `STEPS` ใน [`assets/ecmis-10-2.js`](../assets/ecmis-10-2.js)) ส่วนคอลัมน์ **"มติบอร์ด (badge)"** คือแบดจ์สีที่ต่อท้ายสถานะ ซึ่งจะขึ้น **ตั้งแต่ 10-2-06 บันทึกผลมติแล้วเป็นต้นไป** (อ่านจาก `item.raw.l2ResolutionType` — ดู `resolutionBadge()` ใน [01-work-inbox.html](../01-work-inbox.html)): 🟢 เขียว = อนุญาตเปิดเผย (DISCLOSE), 🟠 ส้ม = อนุญาตเปิดเผยบางส่วน (PARTIAL), 🔴 แดง = ไม่อนุญาตเปิดเผย (DENY)

## Flow 3 — มติบอร์ด: อนุญาตเปิดเผย / อนุญาตเปิดเผยบางส่วน + คดีเสร็จสิ้นแล้ว (DISCLOSE/PARTIAL, CLOSED) — อ้างอิง LAW0058

> ⚠️ **ยังไม่มีไฟล์ของ flow นี้ในระบบ** — ตามผังเดิม (drawio หน้า 5, "5. คดีเสร็จสิ้นแล้ว") flow นี้มี 11 ขั้นตอนเต็ม (LAW0058–LAW0068): รับมติบอร์ด (ธุรการ) → จัดทำบันทึกและมติคณะอนุกรรมการฯ (เลขานุการฯ) → ลงนาม (ผอ.กองกฎหมาย) → ออกเลขหนังสือส่งภายใน (ระบบ E-CMIS) → พิจารณาเสนอเลขาธิการฯ และลงนาม (รองเลขาธิการ ป.ป.ท.) → มติบอร์ดพิจารณาเห็นชอบและลงนามเพื่อเสนอคณะกรรมการ ป.ป.ท. (ระบบ E-CMIS) → รับมติและเสนอ (ธุรการ) → มอบหมายฝ่ายเลขานุการ (ผอ.กองกฎหมาย) → จัดทำบันทึกแจ้งมติ (เลขานุการฯ) → ปกปิดข้อมูลส่วนบุคคลที่อ่อนไหว (**กอง/สำนักเจ้าของสำนวน**) → แจ้งผลผู้ร้อง+สิทธิ์อุทธรณ์ (**กอง/สำนักเจ้าของสำนวน**) — คือรอบเสนอคณะกรรมการ ป.ป.ท. เต็มคณะอีกครั้ง คล้ายกับที่ Flow 1 ได้ต่อขยายไว้แล้ว แต่ปัจจุบันโค้ดยังไม่แยกสถานะคดี (`CASE_STATES`: อยู่ระหว่างไต่สวน/คดีเสร็จสิ้นแล้ว) ออกจาก Flow 2 — คำร้องที่มติ DISCLOSE/PARTIAL ไม่ว่าสถานะคดีจะเป็นอะไรก็เดิน **Flow 2** เหมือนกันหมด
>
> เมื่อตัดสินใจรูปแบบไฟล์ของ flow นี้แล้ว ให้เพิ่มตารางแบบเดียวกับ Flow 1/2 ที่นี่ (พร้อมคอลัมน์สถานะ/มติบอร์ดเช่นเดียวกัน)
>
> ⚠️ **แถวในผัง drawio หน้า 2 ("มติบอร์ด – แยกทางดำเนินการ") ดูสลับกับชื่อหน้า 4/5:** ลูกศรเงื่อนไข "สิ้นสุดแล้ว" ชี้ไป LAW0053 (หน้า 4 ชื่อ "อยู่ระหว่างไต่สวน") และลูกศร "อยู่ระหว่างไต่สวน" ชี้ไป LAW0058 (หน้า 5 ชื่อ "คดีเสร็จสิ้นแล้ว") ซึ่งตรงข้ามกับชื่อหน้าที่ปลายทางจริง น่าจะเป็นความผิดพลาดตอนวาดผังเดิม (label สลับกับปลายลูกศร) เอกสารนี้ยึดตาม**ชื่อหน้า** (Flow 2 = อยู่ระหว่างไต่สวน/LAW0053, Flow 3 = คดีเสร็จสิ้นแล้ว/LAW0058) เป็นหลัก — ควรตรวจสอบกับผู้ออกแบบผังเดิมก่อนเริ่มพัฒนา Flow 3 จริง เผื่อความหมายที่ถูกต้องสลับกัน
