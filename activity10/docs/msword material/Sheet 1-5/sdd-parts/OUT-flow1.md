## LAW0084 — ศาลปกครองออกหมายเรียก ส่งสำเนาคำฟ้องให้ ป.ป.ท.

|---|---|
| Function Name | ออกหมายเรียก ส่งสำเนาคำฟ้องให้ ป.ป.ท. |
| Menu Name | — (ไม่มีหน้าจอในระบบ E-CMIS) |
| Page | — |
| Page Code | LAW0084 |
| ผู้ดำเนินการ | ศาลปกครอง (การกระทำภายนอกระบบ) |

### Description

ยังไม่มีหน้าจอ Prototype สำหรับขั้นตอนนี้ โดยอ้างอิง User Flow LAW0084 เป็นหลัก และจะปรับปรุง User Interface Specification ภายหลังเมื่อ Prototype แล้วเสร็จ

ขั้นตอนนี้เป็นจุดเริ่มต้นของ Flow 1 โดยศาลปกครอง (ชั้นต้นหรือศาลปกครองสูงสุด แล้วแต่กรณี) เป็นผู้ออกหมายเรียกและจัดส่งสำเนาคำฟ้องมายังสำนักงาน ป.ป.ท. ถือเป็นเหตุการณ์ที่เกิดขึ้นนอกระบบ E-CMIS ทั้งหมด และเป็น input ที่ทำให้เกิดขั้นตอนถัดไปคือ LAW0085 (เจ้าหน้าที่ธุรการกองกฎหมายลงทะเบียนรับเรื่องบนระบบ)

จากผัง User Flow (flow01.txt) โหนด `LAW0084` และ `LAW0085` ถูกวางซ้อนตำแหน่งเดียวกัน (x=400, y=10) สะท้อนว่าเป็นจุดเชื่อมต่อโดยตรงระหว่างเหตุการณ์นอกระบบ (ศาล) กับขั้นตอนแรกในระบบ (ธุรการ)

### Condition

—

### Process

1. ศาลปกครองมีคำสั่งออกหมายเรียกในคดีปกครอง และจัดส่งหมายเรียกพร้อมสำเนาคำฟ้องมายังสำนักงาน ป.ป.ท. (ผ่านช่องทางเอกสารภายนอกระบบ)
2. เอกสารดังกล่าวถูกส่งต่อไปยังเจ้าหน้าที่ธุรการกองกฎหมายเพื่อดำเนินการลงทะเบียนรับเรื่องในระบบ E-CMIS ต่อไป (LAW0085)

**Flow ต่อเนื่อง:**
**LAW0084 (ศาลปกครองออกหมายเรียก — ไม่มีหน้าจอ)** → LAW0085 (ธุรการกองกฎหมาย ลงทะเบียนรับเรื่อง)

## LAW0085 — เจ้าหน้าที่ธุรการกองกฎหมาย ลงทะเบียนรับเรื่องบนระบบ E-CMIS

### Description

หน้านี้ใช้สำหรับให้เจ้าหน้าที่ธุรการกองกฎหมายบันทึกรับเรื่องคดี/คำขอที่ส่งเข้ามายังกองกฎหมาย โดยเป็นจุดเริ่มต้นของกระบวนการในระบบ E-CMIS ที่รับข้อมูลต่อเนื่องจาก LAW0084 (หมายเรียกและสำเนาคำฟ้องจากศาลปกครอง) ผู้ใช้งานคือเจ้าหน้าที่ธุรการกองกฎหมาย (บทบาท admin_legal)

ผู้ใช้ต้องกรอกข้อมูลพื้นฐานของการรับเรื่อง ได้แก่ เลขสารบรรณกลาง วันที่รับเอกสาร และหมวดหมู่งานกฎหมาย ซึ่งฟิลด์ "หมวดหมู่งานกฎหมาย" (in_category) เป็นฟิลด์สำคัญที่กำหนดว่าจะแสดงชุดข้อมูลย่อยใดต่อไปในฟอร์ม (เช่น เลือก "คดีศาลปกครอง" รหัส 10.3 ระบบจะแสดงชุดฟิลด์ข้อมูลคดีศาลปกครองเพิ่มเติม) นอกจากนี้ยังมีช่องค้นหาฐานข้อมูลสำนวนคดีเดิม (ป.ป.ท.) เพื่อช่วยเจ้าหน้าที่อ้างอิงสำนวนที่เกี่ยวข้อง

หน้าจอนี้เป็นหน้าเดียวกับที่ใช้ในขั้นตอน LAW0086 (ออกเลขรับและเกษียนหนังสือ) และ LAW0087 (ลงทะเบียนคดีปกครอง) โดยฟิลด์ของทั้งสามขั้นตอนอยู่ในฟอร์มเดียวกันแต่คนละส่วน (section) เมื่อกรอกครบและกดปุ่ม "บันทึก และ เสนอ ผอ.กองกฎหมาย" ระบบจะบันทึก statusCode เป็น `L3_PENDING_DIRECTOR_ASSIGN` และส่งรายการต่อให้ ผอ.กองกฎหมาย (LAW0088)

### Condition

**เงื่อนไขการแสดง Object**

- ส่วนค้นหาสำนวนคดีเดิม (ป.ป.ท.)
- ส่วนข้อมูลรับเรื่องพื้นฐาน (เลขสารบรรณกลาง, วันที่รับเอกสาร, เจ้าหน้าที่ผู้รับเรื่อง, หมวดหมู่งานกฎหมาย)
- ส่วนปุ่มดำเนินการ
- หน้านี้เป็นฟอร์มรับเรื่องรวม (02-board-intake.html) ที่สลับกลุ่มฟิลด์ย่อยตามค่าที่เลือกในฟิลด์ "หมวดหมู่งานกฎหมาย" (in_category) เช่น หมวดคดีอาญาทุจริตฯ (10.1) จะแสดงกลุ่มฟิลด์ความเห็น/คำสั่งพนักงานอัยการ หมวดการขอเปิดเผยข้อมูลข่าวสาร (10.2) จะแสดงกลุ่มฟิลด์ผู้ยื่นคำขอเปิดเผยข้อมูล ส่วน Flow นี้ใช้เฉพาะหมวดคดีศาลปกครอง (10.3) ซึ่งแสดงกลุ่มฟิลด์ข้อมูลคดีศาลปกครอง (รายละเอียดตาม LAW0087)

## LAW0086 — เจ้าหน้าที่ธุรการกองกฎหมาย ออกเลขรับและรับหมายเรียก/สำเนาคำฟ้อง เกษียนหนังสือ

### Description

ขั้นตอนนี้เป็นส่วนหนึ่งของฟอร์ม "บันทึกรับเรื่อง" หน้าเดียวกับ LAW0085 (02-board-intake.html) โดยไม่มี STEP_CODE แยกในระบบ ยังคงใช้ Page Code เดียวกันคือ LAW0085 เจ้าหน้าที่ธุรการกองกฎหมายดำเนินการออกเลขรับกองกฎหมาย (กกม.) และเกษียนหนังสือเสนอเรื่องต่อผู้บังคับบัญชาต่อเนื่องจากการกรอกข้อมูลรับเรื่องใน LAW0085

ส่วนนี้ประกอบด้วยฟิลด์ออกเลขรับกองกฎหมาย และช่องเลือกผู้บังคับบัญชาที่จะเสนอเรื่องต่อ (ปรากฏเป็นค่า dir_legal คือ ผู้อำนวยการกองกฎหมาย) เมื่อกดปุ่ม "บันทึก และ เสนอ ผอ.กองกฎหมาย" ถือเป็นการดำเนินการเกษียนหนังสือส่งต่อเรื่องเสร็จสมบูรณ์

**เงื่อนไขการแสดง Object**

3. ผู้ใช้เลือกผู้บังคับบัญชาที่จะส่งเสนอเรื่อง (ค่าเริ่มต้น/ตัวเลือกคือ ผอ.กองกฎหมาย)
4. ผู้ใช้กดปุ่ม "บันทึก และ เสนอ ผอ.กองกฎหมาย" (onclick=submitReceiveAndForward()) เพื่อบันทึกเลขรับและส่งเรื่องต่อ ระบบตั้งค่า statusCode เป็น `L3_PENDING_DIRECTOR_ASSIGN`

### Description

ขั้นตอนนี้ไม่มีหน้าจอแยกต่างหากในระบบ [ต้องยืนยันจาก Prototype] — ตาม implementation-plan ของทีมพัฒนา ระบบถือว่าขั้นตอนนี้เสร็จสมบูรณ์เมื่อเจ้าหน้าที่ธุรการเลือกหมวดหมู่งานกฎหมายเป็น "คดีศาลปกครอง" (in_category = 10.3) ในฟอร์มเดียวกับ LAW0085/LAW0086 (02-board-intake.html) ซึ่งจะทำให้ระบบแสดงชุดฟิลด์ข้อมูลคดีศาลปกครองเพิ่มเติม เช่น ชื่อหมาย ศาล สั่งถึง หมายเลขคดีดำ หมายเลขคดีแดง ผู้ฟ้อง ผู้ถูกฟ้อง เป็นต้น

### Process

1. เมื่อเจ้าหน้าที่ธุรการกองกฎหมายเลือกหมวดหมู่งานกฎหมายเป็น "คดีศาลปกครอง" ในฟอร์ม LAW0085 ระบบจะแสดงชุดฟิลด์ข้อมูลคดีศาลปกครองเพิ่มเติมดังกล่าวข้างต้น
2. ผู้ใช้กรอกรายละเอียดหมายเรียก (ชื่อหมาย ศาล สั่งถึง หมายเลขคดีดำ/แดง กำหนดเวลาที่ศาลสั่ง) หากเลือกตัวเลือก "อื่นๆ" ในชื่อหมาย ศาล หรือสั่งถึง ระบบแสดงช่องข้อความให้ระบุรายละเอียดเพิ่มเติม
3. ผู้ใช้เพิ่มรายชื่อผู้ฟ้องและผู้ถูกฟ้อง (สามารถเพิ่มได้หลายรายการผ่านปุ่ม "เพิ่มผู้ฟ้อง"/"เพิ่มผู้ถูกฟ้อง")
4. ผู้ใช้กรอกเลขสารบัญ หน่วยงานที่รับเรื่อง และหมายเหตุ (ถ้ามี)
5. ผู้ใช้แนบไฟล์หมายศาลแจ้งให้ทำคำคัดค้านคำขอทุเลา และสามารถแนบเอกสารเพิ่มเติมอื่น ๆ ประกอบคดีได้ (in_courtAttachments)
6. เมื่อกรอกครบถ้วนพร้อมกับข้อมูลใน LAW0085/LAW0086 ผู้ใช้กดปุ่ม "บันทึก และ เสนอ ผอ.กองกฎหมาย" ถือว่าคดีศาลปกครองถูกลงทะเบียนเข้าสู่ระบบ E-CMIS เรียบร้อย และส่งรายการต่อให้ ผอ.กองกฎหมาย (LAW0088)

**Flow ต่อเนื่อง:**
LAW0086 (ธุรการกองกฎหมาย ออกเลขรับและเกษียนหนังสือ) → **LAW0087 (ธุรการกองกฎหมาย ลงทะเบียนคดีปกครอง)** → LAW0088 (ผอ.กองกฎหมาย ลงนามมอบหมาย)

### Description

หน้านี้ใช้สำหรับให้ผู้อำนวยการกองกฎหมายตรวจสอบรายละเอียดคดีศาลปกครองที่เจ้าหน้าที่ธุรการกองกฎหมายบันทึกรับเรื่องไว้ (ต่อเนื่องจาก LAW0085–LAW0087) และลงนามสั่งการมอบหมายเรื่องต่อไปยังผู้อำนวยการกลุ่มงานคดี ผู้ดำเนินการคือ ผอ.กองกฎหมาย (บทบาท dir_legal)

ผู้ใช้ต้องตรวจสอบรายละเอียดคดี (เลขรับกองกฎหมาย ชื่อหมาย ศาล สั่งถึง หมายเลขคดีดำ/แดง ผู้ฟ้อง ผู้ถูกฟ้อง เลขสารบัญ หมายเหตุ และเอกสารแนบ) ก่อนออกคำสั่งมอบหมายงานให้กลุ่มงานคดีที่รับผิดชอบ พร้อมระบุวันที่สั่งการและข้อสั่งการ/ความเห็นเพิ่มเติม (ถ้ามี)

เมื่อผู้ใช้กดปุ่ม "ลงนาม และ สั่งการ" ระบบจะบันทึก statusCode เป็น `L3_PENDING_GROUP_ASSIGN` และส่งรายการต่อไปยังผู้อำนวยการกลุ่มงานคดี (LAW0089) เพื่อมอบหมายนิติกรผู้รับผิดชอบต่อไป
