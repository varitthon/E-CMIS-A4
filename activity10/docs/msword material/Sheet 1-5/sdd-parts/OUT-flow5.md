# Flow 5: รับคำพิพากษาศาลปกครองชั้นต้น (LAW0116 – LAW0123)

## LAW0116 — ศาลปกครอง มีคำพิพากษา

| หัวข้อ | รายละเอียด |
|---|---|
| Function Name | ศาลปกครองมีคำพิพากษา |
| Menu Name | — |
| Page | — ไม่มีหน้าจอ [รอยืนยัน URL / Page จริงจาก Prototype] |
| Page Code | — |
| ผู้ดำเนินการ | ศาลปกครอง (หน่วยงานภายนอกระบบ) |

### Description

ยังไม่มีหน้าจอ Prototype สำหรับขั้นตอนนี้ โดยอ้างอิง User Flow LAW0116 เป็นหลัก และจะปรับปรุง User Interface Specification ภายหลังเมื่อ Prototype แล้วเสร็จ

ขั้นตอนนี้เป็นจุดเริ่มต้นของ Flow 5 โดยศาลปกครอง (ชั้นต้น) มีคำพิพากษาในคดีที่สำนักงาน ป.ป.ท. เป็นคู่ความ ซึ่งเป็นเหตุการณ์ที่เกิดขึ้นภายนอกระบบ E-CMIS

### Condition

—

### Process

1. ศาลปกครองชั้นต้นพิจารณาคดีเสร็จสิ้นและมีคำพิพากษา (เหตุการณ์ภายนอกระบบ ไม่มีการบันทึกข้อมูลในระบบ E-CMIS ณ ขั้นตอนนี้)
2. คำพิพากษาที่เกิดขึ้นจะถูกจัดส่งเป็นหนังสือแจ้งผลไปยังหน่วยงานที่เกี่ยวข้องในขั้นตอนถัดไป (LAW0117)

LAW0115 (นิติกรจัดส่งคำให้การทางไปรษณีย์) → **LAW0116 (ศาลปกครองมีคำพิพากษา)** → LAW0117 (มีหนังสือแจ้งผลคำพิพากษามาที่สำนักงาน ป.ป.ท.)

## LAW0117 — มีหนังสือแจ้งผลคำพิพากษาของศาลปกครองชั้นต้นมาทางสำนักงาน ป.ป.ท.

| หัวข้อ | รายละเอียด |
|---|---|
| Function Name | รับหนังสือแจ้งผลคำพิพากษาจากสำนักงานคดีปกครอง |
| Menu Name | — |
| Page | — ไม่มีหน้าจอ [รอยืนยัน URL / Page จริงจาก Prototype] |
| Page Code | — |
| ผู้ดำเนินการ | สำนักงานคดีปกครอง (อัยการ) |

### Description

ยังไม่มีหน้าจอ Prototype สำหรับขั้นตอนนี้ โดยอ้างอิง User Flow LAW0117 เป็นหลัก และจะปรับปรุง User Interface Specification ภายหลังเมื่อ Prototype แล้วเสร็จ

ขั้นตอนนี้เกิดขึ้นภายนอกระบบ E-CMIS โดยสำนักงานคดีปกครอง (อัยการ) จัดทำและจัดส่งหนังสือแจ้งผลคำพิพากษาของศาลปกครองชั้นต้นมายังสำนักงาน ป.ป.ท. เพื่อให้หน่วยงานที่เกี่ยวข้องดำเนินการรับเรื่องต่อไป

### Condition

—

### Process

1. สำนักงานคดีปกครอง (อัยการ) จัดทำหนังสือแจ้งผลคำพิพากษาของศาลปกครองชั้นต้น (เหตุการณ์ภายนอกระบบ ไม่มีการบันทึกข้อมูลในระบบ E-CMIS ณ ขั้นตอนนี้)
2. จัดส่งหนังสือแจ้งผลคำพิพากษามายังสำนักงาน ป.ป.ท. เพื่อเข้าสู่กระบวนการลงทะเบียนรับเรื่องในขั้นตอนถัดไป (LAW0118)

**Flow ต่อเนื่อง:**
LAW0116 (ศาลปกครองมีคำพิพากษา) → **LAW0117 (มีหนังสือแจ้งผลคำพิพากษามาที่สำนักงาน ป.ป.ท.)** → LAW0118 (สารบรรณกลางลงทะเบียนรับเรื่อง)

## LAW0118 — สารบรรณกลางลงทะเบียนรับเรื่อง

| หัวข้อ | รายละเอียด |
|---|---|
| Function Name | ลงทะเบียนรับหนังสือแจ้งผลคำพิพากษา (สารบรรณ) |
| Menu Name | — |
| Page | — ไม่มีหน้าจอ (ลงทะเบียนรับในระบบสารบรรณ ไม่ใช่ E-CMIS) [รอยืนยัน URL / Page จริงจาก Prototype] |
| Page Code | — |
| ผู้ดำเนินการ | เจ้าหน้าที่สารบรรณกลาง |

### Description

ยังไม่มีหน้าจอ Prototype สำหรับขั้นตอนนี้ โดยอ้างอิง User Flow LAW0118 เป็นหลัก และจะปรับปรุง User Interface Specification ภายหลังเมื่อ Prototype แล้วเสร็จ

ขั้นตอนนี้เจ้าหน้าที่สารบรรณกลางของสำนักงาน ป.ป.ท. รับหนังสือแจ้งผลคำพิพากษาที่จัดส่งมาจากสำนักงานคดีปกครอง (LAW0117) และลงทะเบียนรับเรื่องในระบบสารบรรณกลางของหน่วยงาน ซึ่งเป็นระบบงานสารบรรณทั่วไป ไม่ใช่ระบบ E-CMIS จึงไม่มีหน้าจอ Prototype ของ E-CMIS สำหรับขั้นตอนนี้ เมื่อลงทะเบียนรับเรื่องแล้วจึงส่งต่อเอกสารไปยังกองกฎหมายเพื่อเข้าสู่กระบวนการรับหนังสือแจ้งผลคำพิพากษาในระบบ E-CMIS (LAW0119) ต่อไป

### Condition

—

### Process

1. เจ้าหน้าที่สารบรรณกลางรับหนังสือแจ้งผลคำพิพากษาที่จัดส่งมาจากสำนักงานคดีปกครอง
2. ลงทะเบียนรับเรื่องในระบบสารบรรณกลาง (ระบบภายนอก E-CMIS ไม่มีการบันทึกข้อมูลในระบบ E-CMIS ณ ขั้นตอนนี้)
3. จัดส่งเอกสารต่อไปยังกองกฎหมายเพื่อดำเนินการรับหนังสือในระบบ E-CMIS (LAW0119)

**Flow ต่อเนื่อง:**
LAW0117 (มีหนังสือแจ้งผลคำพิพากษามาที่สำนักงาน ป.ป.ท.) → **LAW0118 (สารบรรณกลางลงทะเบียนรับเรื่อง)** → LAW0119 (ธุรการรับหนังสือแจ้งผลคำพิพากษา)

## LAW0119 — ธุรการกองกฎหมาย รับหนังสือแจ้งผลคำพิพากษา

### Description

หน้าจอนี้ใช้สำหรับให้เจ้าหน้าที่ธุรการกองกฎหมายบันทึกข้อมูลการรับหนังสือแจ้งผลคำพิพากษาศาลปกครองชั้นต้น ซึ่งจัดส่งมาจากสารบรรณกลางของสำนักงาน ป.ป.ท. (ขั้นตอน LAW0118) เข้าสู่ระบบ E-CMIS เจ้าหน้าที่ธุรการต้องบันทึกทั้งข้อมูลการรับจากฝ่ายสารบรรณกลาง และรายละเอียดของหนังสือแจ้งผลคำพิพากษา รวมถึงสามารถค้นหาคดีรับคำฟ้องเดิมเพื่อเชื่อมโยงข้อมูลคดีที่เกี่ยวข้องได้

หน้าจอเดียวกันนี้ยังใช้สำหรับขั้นตอนลงทะเบียนคดีปกครอง (LAW0120) ต่อเนื่องในฟอร์มเดียวกัน โดยรายละเอียดของ LAW0120 แยกอธิบายไว้ในหัวข้อถัดไป เมื่อเจ้าหน้าที่ธุรการกรอกข้อมูลครบถ้วนและกดยืนยันแล้ว ระบบจะบันทึกสถานะเป็น `L3V_PENDING_DIRECTOR_ASSIGN` และส่งเรื่องต่อไปยังผู้อำนวยการกองกฎหมายเพื่อพิจารณามอบหมายงานต่อไป (LAW0121)

### Process

1. เจ้าหน้าที่ธุรการกองกฎหมายเข้าสู่หน้าจอ "ธุรการ รับผลคำพิพากษาศาลปกครองชั้นต้น" จากเมนูงานกฎหมายในทางคดี
2. ระบบแสดงการ์ด "ข้อมูลการรับจากฝ่ายสารบรรณกลาง" ให้เจ้าหน้าที่กรอกเลขสารบรรณกลาง วันที่รับเอกสาร และเลขรับกองกฎหมาย
3. เจ้าหน้าที่สามารถค้นหาคดีรับคำฟ้องเดิมที่เกี่ยวข้อง (ไม่บังคับ) ผ่านช่อง "ค้นหาคดีรับคำฟ้องเดิม" และปุ่ม "🔍 ค้นหาคดี"
4. เจ้าหน้าที่กรอกรายละเอียดหนังสือแจ้งผลคำพิพากษาในการ์ด "รายละเอียดหนังสือแจ้งผลคำพิพากษา" ได้แก่ ศาล วันที่ศาลมีคำพิพากษา หมายเลขคดีดำ หมายเลขคดีแดง เลขที่หนังสือแจ้งผลคำพิพากษา ลงวันที่หนังสือแจ้ง วันที่สำนักงาน ป.ป.ท. รับเรื่อง รายชื่อผู้ฟ้องและผู้ถูกฟ้อง เลขสารบัญ หน่วยงานที่รับเรื่อง หมายเหตุ และแนบเอกสารคำพิพากษา (ถ้ามี)

### Description

หน้าจอนี้ใช้สำหรับให้ผู้อำนวยการกลุ่มงานคดีตรวจสอบรายละเอียดคำพิพากษาที่ได้รับมอบหมายจากผู้อำนวยการกองกฎหมาย (LAW0121) และดำเนินการมอบหมายนิติกรกลุ่มงานคดีให้เป็นผู้รับผิดชอบตรวจสอบและวิเคราะห์คำพิพากษาต่อไป

ข้อมูลรายละเอียดคำพิพากษาและข้อสั่งการจากผู้อำนวยการกองกฎหมายแสดงเป็น Read-only ในส่วนบนของหน้าจอ ผู้อำนวยการกลุ่มงานคดีสามารถดาวน์โหลดเอกสารแนบคำพิพากษาเพื่อตรวจสอบประกอบได้ ส่วนล่างของหน้าจอเป็นแบบฟอร์มสำหรับระบุนิติกรผู้รับมอบหมาย วันที่มอบหมาย และข้อสั่งการ/หมายเหตุ เมื่อผู้อำนวยการกลุ่มงานคดีกดยืนยันแล้ว ระบบจะบันทึกสถานะเป็น `L3V_PENDING_LAWYER_ANALYSIS` และส่งเรื่องต่อไปยังนิติกรกลุ่มงานคดีเพื่อตรวจสอบคำพิพากษาต่อไป (LAW0123)

### Process

1. ผู้อำนวยการกลุ่มงานคดีเข้าสู่หน้าจอ "ผอ.กลุ่มงาน มอบหมายนิติกร (คำพิพากษา)" จากรายการเรื่องที่ผู้อำนวยการกองกฎหมายมอบหมายมา
2. ระบบแสดงรายละเอียดคำพิพากษาศาลปกครองชั้นต้นและข้อสั่งการจากผู้อำนวยการกองกฎหมายแบบ Read-only รวมถึงปุ่มดาวน์โหลดเอกสารแนบคำพิพากษา
3. ผู้อำนวยการกลุ่มงานคดีตรวจสอบข้อมูลและเอกสารแนบ
4. ผู้อำนวยการกลุ่มงานคดีระบุนิติกรผู้รับมอบหมาย วันที่มอบหมาย และข้อสั่งการ/หมายเหตุ (ถ้ามี) ในการ์ด "มอบหมายนิติกรผู้รับผิดชอบ ผอ.กลุ่มงานคดี"
5. ผู้อำนวยการกลุ่มงานคดีกดปุ่ม "ลงนาม และ มอบหมาย" (onclick=submitForm())
6. ระบบบันทึกข้อมูล เปลี่ยนสถานะรายการเป็น `L3V_PENDING_LAWYER_ANALYSIS` และส่งเรื่องต่อไปยังนิติกรกลุ่มงานคดีเพื่อตรวจสอบคำพิพากษา (LAW0123)

## LAW0123 — นิติกรกลุ่มงานคดี ตรวจสอบคำพิพากษา เพื่อหามูลเหตุคดี

### Description

หน้าจอนี้ใช้สำหรับให้นิติกรกลุ่มงานคดีที่ได้รับมอบหมาย (จากขั้นตอน LAW0122) ตรวจสอบรายละเอียดคำพิพากษาศาลปกครองชั้นต้น พิจารณาประเด็นแห่งคดี/มูลเหตุคดี และบันทึกผลคำพิพากษาเบื้องต้น ได้แก่ ผลคดี วันที่อ่าน/รับทราบคำพิพากษา และวันครบกำหนดอุทธรณ์

หน้าจอ `10-3v-04-lawyer-verdict-analysis.html` นี้ตามโครงสร้างของ Prototype มีขอบเขตครอบคลุมมากกว่า LAW0123 โดยรวมส่วนของ LAW0124 (วิเคราะห์ผลคำพิพากษาและบันทึกความเห็น) และ LAW0125 (แนวทางที่เสนอ นิติกร) ไว้ในฟอร์มเดียวกันด้วย เอกสารฉบับนี้ขอบเขตจำกัดเฉพาะส่วน LAW0123 คือการตรวจสอบคำพิพากษาเพื่อหามูลเหตุคดีและบันทึกผลคำพิพากษาเท่านั้น ส่วนการ์ด "วิเคราะห์ผลคำพิพากษาและบันทึกความเห็น" และ "แนวทางที่เสนอ นิติกร" อยู่นอกขอบเขตของหัวข้อ LAW0116–LAW0123 นี้และควรจัดทำแยกไว้ในเอกสารของ Flow ถัดไป (LAW0124 เป็นต้นไป)

Business Rule สำคัญของหน้านี้คือช่อง "ผู้ฟ้องคดียื่นอุทธรณ์หรือไม่" (ที่ผูกกับตัวเลือกผลคดี "ชนะคดี") จะแสดงเฉพาะเมื่อนิติกรเลือกผลคดีเป็น "ชนะคดี" เท่านั้น หากเลือกผลคดีเป็น "แพ้คดี" หรือ "แพ้บางส่วน" ระบบจะไม่แสดงช่องดังกล่าว แต่จะให้พิจารณาความเห็นควรอุทธรณ์แทน เมื่อนิติกรบันทึกข้อมูลครบถ้วนและกดยืนยันแล้ว ระบบจะบันทึกสถานะเป็น `L3V_PENDING_GROUP_APPROVE` และส่งเรื่องต่อไปยังขั้นตอนถัดไป

### Process

1. นิติกรกลุ่มงานคดีเข้าสู่หน้าจอ "นิติกร วิเคราะห์ผลคำพิพากษา" จากรายการเรื่องที่ผู้อำนวยการกลุ่มงานคดีมอบหมายมา
2. ระบบแสดงข้อมูลคำพิพากษาศาลปกครองชั้นต้นและข้อสั่งการจากผู้อำนวยการกลุ่มงานคดีแบบ Read-only รวมถึงปุ่มดาวน์โหลดเอกสารแนบคำพิพากษา
3. นิติกรตรวจสอบเอกสารคำพิพากษาและบันทึกประเด็นแห่งคดี/มูลเหตุคดี (ถ้ามี) ในการ์ด "ตรวจสอบคำพิพากษา / มูลเหตุคดี นิติกร"
4. นิติกรเลือกผลคดีในการ์ด "บันทึกผลคำพิพากษา" จาก 3 ตัวเลือก ได้แก่ ชนะคดี / แพ้คดี / แพ้บางส่วน
5. กรณีเลือก "ชนะคดี" ระบบแสดงบล็อกคำถาม "ผู้ฟ้องคดียื่นอุทธรณ์?" (`#grp_appealByPlaintiff`) เพิ่มเติมให้นิติกรระบุ (เลือก id `appeal_yes` หรือ `appeal_no`) ส่วนกรณีเลือก "แพ้คดี" หรือ "แพ้บางส่วน" ระบบจะซ่อนบล็อกนี้และล้างค่าที่เคยเลือกไว้ทิ้งทันที โดยให้นิติกรพิจารณาความเห็นควรอุทธรณ์แทน
6. นิติกรกรอกสรุปคำพิพากษา (ถ้ามี) วันที่อ่าน/รับทราบคำพิพากษา และตรวจสอบ/แก้ไขวันครบกำหนดอุทธรณ์
7. นิติกรตรวจสอบข้อมูลทั้งหมดแล้วกดปุ่ม "บันทึก และ ส่งต่อ" (onclick=submitForm())
8. ระบบบันทึกข้อมูล เปลี่ยนสถานะรายการเป็น `L3V_PENDING_GROUP_APPROVE` และส่งเรื่องต่อเข้าสู่กระบวนการวิเคราะห์ผลคำพิพากษาและกำหนดแนวทางต่อไป (LAW0124 เป็นต้นไป — อยู่นอกขอบเขตของเอกสารฉบับนี้)

**Flow ต่อเนื่อง:**
LAW0122 (ผอ.กลุ่มงาน มอบหมายนิติกร) → **LAW0123 (นิติกร ตรวจสอบคำพิพากษา เพื่อหามูลเหตุคดี)** → LAW0124 (วิเคราะห์ผลคำพิพากษา/กำหนดแนวทาง — นอกขอบเขตเอกสารฉบับนี้)
