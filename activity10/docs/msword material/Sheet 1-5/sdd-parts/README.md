# ไฟล์ต้นทางของเอกสาร SDD

แต่ละไฟล์คือหัวข้อ SDD ของกระบวนงานหนึ่งช่วง แก้ไฟล์เหล่านี้แล้วรัน `npm run sdd`
เพื่อประกอบใหม่เป็น `SDD-10.3-LAW0084-LAW0123.md` ที่ root ของโปรเจกต์

| ไฟล์ | ครอบคลุม |
|---|---|
| `OUT-flow1.md` | LAW0084–LAW0096 รับคำฟ้อง – สรุปความเห็นเสนอบอร์ด |
| `OUT-flow23.md` | LAW0097–LAW0102 คำชี้แจงคัดค้านคำขอทุเลาฯ และคำสั่งศาล |
| `OUT-flow4a.md` | LAW0103–LAW0109 จัดทำคำให้การแก้คำฟ้อง ช่วงต้น |
| `OUT-flow4b.md` | LAW0110–LAW0115 จัดทำคำให้การแก้คำฟ้อง ช่วงท้าย + ขั้นตอน L3-33 |
| `OUT-flow5.md` | LAW0116–LAW0123 รับคำพิพากษาศาลปกครองชั้นต้น |

ส่วนหัวเอกสาร สารบัญ และตารางอ้างอิงขั้นตอน สร้างอัตโนมัติจาก `screen-map.json`
และ `capture-result.json` โดย `build-sdd.mjs` ไม่ต้องแก้ด้วยมือ

ข้อมูล Field ที่ใช้เขียนหัวข้อ Condition ดึงมาจาก Prototype จริงด้วย
`npm run fields` -> `field-inventory.json` (ช่องที่มองเห็นตอนเปิดหน้า)
และ `hidden-blocks.json` (บล็อกที่แสดงตามเงื่อนไข)
