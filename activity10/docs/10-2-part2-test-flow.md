## 📌 7. ผลการทดสอบจริงในรอบนี้ (ก่อนแก้ไขจุดส่งกิจกรรมที่ 7)

ทดสอบผ่าน browser ด้วยข้อมูลจำลอง (ไม่ใช่ mock data ใน `INITIAL_CASES` — สร้างผ่าน console ชั่วคราว) ครบทั้ง 3 สาขา ก่อนพบจุดที่ต้องแก้ (ข้อ 0):

- DISCLOSE: 10-2-10 → 10-2-11 (ข้าม 12) → 10-2-13 → 10-2-14 (ปิดคำร้อง) — ไม่มี console error
- PARTIAL: 10-2-10 → 10-2-11 → 10-2-12 → (ลู่เข้า 10-2-13 เดียวกับ DISCLOSE) — ไม่มี console error
- DENY (ก่อนแก้): 10-2-10 → 10-2-15 → 10-2-16 → 10-2-17(เดิม) → 10-2-18(เดิม) → 10-2-19(เดิม) → 10-2-20(เดิม, ปิดคำร้อง) — ไม่มี console error

หลังแก้ไขตามข้อ 0 (แยก `10-2-16`/`10-2-17` ใหม่ และเลื่อนเลขไฟล์ที่เหลือ) ได้ทดสอบซ้ำเฉพาะจุดที่เปลี่ยน (`10-2-16` → `10-2-17` ใหม่ → routing เข้า `10-2-18`) ยืนยันว่า statusCode และ `Activity102.ROUTES` ทำงานถูกต้องตามที่ออกแบบไว้ — **ยังไม่ได้ทดสอบซ้ำครบทั้งสาขา DENY ตั้งแต่ต้นหลังแก้ไข** แนะนำให้รันซ้ำตามตาราง §3 ก่อนใช้งานจริง
