# Page 11: แจ้งความประสงค์ไม่อุทธรณ์ (LAW0164-0171, LAW0163)

**Diagram ID:** p103_11
**Activity codes:** LAW0164 - LAW0171, LAW0163
**Roles (lanes) in this page:** ผอ.กองกฎหมาย, ผอ.กลุ่มงานคดี, นิติกร กลุ่มงานคดี

**Entry point from:** [Page 9, Part 9b](flow-page-09.md) — เงื่อนไข "มติเห็นชอบไม่อุทธรณ์"

## Part 1 — Main Flow

| Step | Role | Action | Status |
|---|---|---|---|
| เริ่มต้น | นิติกร กลุ่มงานคดี | จุดเริ่มต้น (เข้าเงื่อนไขจาก Page 9) | เริ่มกระบวนการแจ้งความประสงค์ไม่อุทธรณ์ |
| LAW0164 | นิติกร กลุ่มงานคดี | รับเรื่องเพื่อดำเนินการแจ้งผล | รับเรื่องแจ้งไม่อุทธรณ์แล้ว |
| LAW0165 | ผอ.กลุ่มงานคดี | พิจารณาเเละเห็นชอบ | ผอ.กลุ่มงานคดีเห็นชอบ |
| LAW0166 | ผอ.กองกฎหมาย | พิจารณาและมอบหมายงาน | มอบหมายงานจัดทำหนังสือแล้ว |
| (เพิ่ม) | ผอ.กลุ่มงานคดี | รับมอบหมายจากผอ.กองกฎหมาย และมอบหมายนิติกรดำเนินการ | มอบหมายนิติกรดำเนินการแล้ว |
| LAW0167 | นิติกร กลุ่มงานคดี | จัดทำหนังสือส่งภายนอกถึงอัยการ | อยู่ระหว่างจัดทำหนังสือแจ้งอัยการ |
| LAW0168 | ผอ.กลุ่มงานคดี | ตรวจสอบหนังสือ | ผอ.กลุ่มงานคดีตรวจหนังสือแล้ว |
| LAW0169 | ผอ.กองกฎหมาย | ลงนามในหนังสือที่ส่งถึงอัยการ | ผอ.กองกฎหมายลงนามหนังสือแล้ว |
| LAW0170 | ธุรการกองกฎหมาย (E-CMIS) | ออกเลขหนังสือ | ออกเลขหนังสือแล้ว |
| LAW0171 | นิติกร กลุ่มงานคดี | ส่งหนังสือเเจ้งความประสงค์ไม่อุทธรณ์ไปยังสำนักงานคดีปกครอง ทางไปรษณีย์ | จัดส่งหนังสือแจ้งไม่อุทธรณ์แล้ว |
| LAW0163 | นิติกร กลุ่มงานคดี | ดำเนินการตามคำพิพากษา (ถ้ามี)/บันทึกคดีถึงที่สุด/ปิดสำนวน | ปิดสำนวนคดีแล้ว |
| สิ้นสุด | — | จุดสิ้นสุด | เสร็จสิ้น (จบกระบวนการทั้งหมด — สายไม่อุทธรณ์) |

**Note:** LAW0163 ในหน้านี้เป็นโหนดเดียวกับที่ปรากฏใน [Page 10](flow-page-10.md) (ปิดสำนวนหลังดำเนินการอุทธรณ์จนถึงที่สุด) — เป็นจุดปิดสำนวนร่วมของทั้งสองสาย (อุทธรณ์ / ไม่อุทธรณ์)

**Note 2:** แถวที่ไม่มีรหัส LAW (เพิ่ม) คือขั้นตอนที่เพิ่มเข้ามาเพื่อให้สายบังคับบัญชาภายในกองกฎหมาย (ผอ.กองกฎหมาย ↔ ผอ.กลุ่มงานคดี ↔ นิติกร) ครบถ้วนไม่ข้ามลำดับชั้น และ LAW0170 ปรับบทบาทจากนิติกรเป็นธุรการกองกฎหมาย (E-CMIS) เนื่องจากเป็นงานออกเลขหนังสือ — ยังไม่ได้ปรับปรุงในไฟล์ .drawio ต้นฉบับ
