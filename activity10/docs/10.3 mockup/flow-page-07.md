## Part 1 — Main Flow

| Step | Role | Action | Status |
|---|---|---|---|
| เริ่มต้น | ศาลปกครอง | จุดเริ่มต้น (เข้าเงื่อนไขจาก Page 6) | เริ่มกระบวนการจัดทำคำแก้อุทธรณ์ |
| LAW0129 | ศาลปกครอง | ส่งสำเนาคำอุทธรณ์ของผู้ฟ้องคดี ให้ ป.ป.ท. จัดทำคำแก้อุทธรณ์ | ศาลส่งสำเนาคำอุทธรณ์แล้ว |
| LAW0130 | สำนักงานคดีปกครอง (อัยการ) | มีหนังสือเเจ้งคำสั่งศาลให้ทำคำเเก้อุทธรณ์มาที่สำนักงาน ป.ป.ท | รับแจ้งคำสั่งศาลให้ทำคำแก้อุทธรณ์ |
| LAW0131 | ธุรการกองกฎหมาย (E-CMIS) | โดยสารบรรณกลางลงทะเบียนรับเรื่อง | ลงทะเบียนรับเรื่อง (สารบรรณ) |
| LAW0132 | ธุรการกองกฎหมาย (E-CMIS) | รับหนังสือเเจ้งผลคำพิพากษา | รับหนังสือแจ้งคำสั่งศาลแล้ว |
| (เพิ่ม) | ผอ.กองกฎหมาย | พิจารณาและมอบหมายให้ผอ.กลุ่มงานคดีดำเนินการ | มอบหมายผอ.กลุ่มงานคดีแล้ว |
| (เพิ่ม) | ผอ.กลุ่มงานคดี | มอบหมายนิติกรผู้รับผิดชอบดำเนินการ | มอบหมายนิติกรดำเนินการแล้ว |
| LAW0133 | นิติกร กลุ่มงานคดี | ลงทะเบียนคดีปกครอง (สมุดคุม MS Excel) | ลงทะเบียนคดีในสมุดคุมแล้ว |
| LAW0134 | ผอ.กลุ่มงานคดี | พิจารณาเเละเห็นชอบ | ผอ.กลุ่มงานคดีเห็นชอบ |
| LAW0135 | ผอ.กองกฎหมาย | แจกจ่าย/มอบหมาย ให้นิติกรรับผิดชอบ | มอบหมายนิติกรรับผิดชอบแล้ว |
| (เพิ่ม) | ผอ.กลุ่มงานคดี | รับมอบหมายจากผอ.กองกฎหมาย และมอบหมายนิติกรดำเนินการ | มอบหมายนิติกรดำเนินการแล้ว |
| LAW0136 | นิติกร กลุ่มงานคดี | ตรวจสอบคำพิพากษา ศึกษาคำอุทธรณ์ของคู่กรณี | อยู่ระหว่างศึกษาคำอุทธรณ์คู่กรณี |
| LAW0137 | นิติกร กลุ่มงานคดี | ร่างคำแก้อุทธรณ์ | อยู่ระหว่างร่างคำแก้อุทธรณ์ |
| LAW0138 | ผอ.กลุ่มงานคดี | ตรวจสอบร่างคำเเก้อุทธรณ์ | ผอ.กลุ่มงานคดีตรวจร่างแล้ว |
| LAW0139 | ผอ.กองกฎหมาย | พิจารณาเเละลงนามในร่างคำเเก้อุทธรณ์เเละหนังสือถึงสำนักงานคดีปกครอง | ผอ.กองกฎหมายลงนามร่างแล้ว |
| LAW0140 | ธุรการกองกฎหมาย (E-CMIS) | ออกเลขหนังสือส่งภายนอก | ออกเลขส่งภายนอกแล้ว |
| LAW0141 | นิติกร กลุ่มงานคดี | ส่งหนังสือเเละร่างคำเเก้อุทธรณ์ไปยังสำนักงานคดีปกครอง ทางไปรษณีย์ | จัดส่งคำแก้อุทธรณ์ทางไปรษณีย์แล้ว |
| ไป LAW0161 | นิติกร กลุ่มงานคดี | ส่งต่อไปยังกิจกรรมที่ 10 | ส่งต่อกิจกรรมที่ 10 |
