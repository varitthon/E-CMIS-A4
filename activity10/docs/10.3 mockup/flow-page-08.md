| LAW0144 | ธุรการกองกฎหมาย (E-CMIS) | รับหนังสือเเจ้งผลคำพิพากษา | รับหนังสือแจ้งผลคำพิพากษาแล้ว |
| (เพิ่ม) | ผอ.กองกฎหมาย | พิจารณาและมอบหมายให้ผอ.กลุ่มงานคดีดำเนินการ | มอบหมายผอ.กลุ่มงานคดีแล้ว |

| LAW0145 | นิติกร กลุ่มงานคดี | ลงทะเบียนคดีปกครอง (สมุดคุม MS Excel) | ลงทะเบียนคดีในสมุดคุมแล้ว |
| LAW0146 | ผอ.กลุ่มงานคดี | พิจารณาเเละเห็นชอบ | ผอ.กลุ่มงานคดีเห็นชอบ |
| LAW0147 | ผอ.กองกฎหมาย | แจกจ่าย/มอบหมาย ให้นิติกรรับผิดชอบ | มอบหมายนิติกรรับผิดชอบแล้ว |
| (เพิ่ม) | ผอ.กลุ่มงานคดี | รับมอบหมายจากผอ.กองกฎหมาย และมอบหมายนิติกรดำเนินการ | มอบหมายนิติกรดำเนินการแล้ว |
| LAW0148 | นิติกร กลุ่มงานคดี | ตรวจสอบคำพิพากษา | อยู่ระหว่างตรวจสอบคำพิพากษา |
